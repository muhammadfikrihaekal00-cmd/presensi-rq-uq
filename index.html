Aplikasi ini berbasis Progressive Web App (PWA), dapat dipasang langsung di layar utama HP seperti aplikasi APK Android atau iOS tanpa melalui Google Play Store.

1
Buka di Google Chrome

Buka tautan web aplikasi ini melalui peramban Google Chrome di HP Anda.

2
Tekan Menu Titik Tiga (⋮)

Tekan tombol menu titik tiga di pojok kanan atas peramban Chrome.

3
Pilih "Instal Aplikasi" / "Tambahkan ke Layar Utama"

Ikon RQ Presensi akan langsung muncul di beranda HP Anda layaknya aplikasi APK native!

1
Buka di Safari iPhone

2
Tekan Tombol Bagikan (Share ⎋)

Koneksi Google Spreadsheet

Database online berbasis Google Spreadsheet (Excel Online)
Status Koneksi
⚪ Belum Terhubung
Data masih disimpan lokal di browser ini saja.

Tempelkan URL Web App Google Spreadsheet Anda di bawah ini:

URL ini didapatkan dari menu Deploy > New deployment > Web app di Google Spreadsheet Anda.

Langkah Mudah Membuat Database Google Spreadsheet:

  1. Buka sheets.new (atau buat file Google Spreadsheet baru di Google Drive Anda).
  2. Beri nama spreadsheet misalnya: Data Presensi RQ Ummul Qasim.
  3. Di menu atas Google Spreadsheet, klik Ekstensi > Apps Script.
  4. Hapus tulisan bawaan di editor Apps Script, lalu klik tombol biru di bawah ini untuk menyalin kodenya:
    Lalu tempelkan (Paste) di editor Apps Script tersebut.
  5. Klik tombol Deploy (kanan atas) > New deployment (Deployment baru).
  6. Pilih jenis Web app, lalu atur:
    • Execute as: Me
    • Who has access: Anyone (Siapa saja)
  7. Klik Deploy > izinkan akses akun Google Anda > salin Web app URL yang berakhiran /exec.
  8. Tempelkan URL tersebut ke tab Tautan Spreadsheet di atas, lalu klik Simpan & Hubungkan. Selesai!
